# linux-sysadmin-lab

Hands-on Linux sysadmin and security lab: Bash scripts, Ansible playbooks and Docker exercises.

## Purpose
Personal learning lab, built on a personal Ubuntu VM. No company data or proprietary benchmark content is included.

## Contents
| Folder | What it contains | Status |
|---|---|---|
| `bash/` | Shell scripts for system checks and automation | In progress |
| `ansible/` | Playbooks for configuration and hardening | Planned |
| `docker/` | Dockerfiles and Compose exercises | Planned |
| `notes/` | Short notes on what I learn | Ongoing |

## Notes
Security controls are referenced by their general topic only. Scripts are tested on a personal Ubuntu VM.
